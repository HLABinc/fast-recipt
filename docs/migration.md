# 本番の移行手順(経費フォーム・予実管理シート)

予算の選択肢を予算タブから同期する構成へ、本番フォームとシートを**その場で**移行する(フォームの URL は変わらない)。
コードは `gas/Code.js`。本番 ID は `gas/config.js`(git 管理外)の `PROD_FORM_ID` / `PROD_SHEET_ID`。

## 何が変わるか

- フォーム: 予算ごとの古いセクションを消し、「予算選択 → ハウス / 委員会 / クラブ / マイプロ → 費用詳細入力」の流れにする。委員会・クラブ・マイプロの選択肢は `予算名｜予算項目`。口座登録の分岐はそのまま。
- シート: `プロセスチェックシート` の右端に「予算名(集計用)」「予算項目(集計用)」の 2 列を足し、新旧の回答を同じ形にそろえる。予算タブの SUMIFS をこの 2 列に向け直す。
- 既存の回答・承認(CJ)・払い戻し(CK)は動かさない。

## リハーサル(コピーで確認済み 2026-11)

`step1`〜`step6` を本番のコピーで実行した結果:

- 移行前後で予算タブの値の差分 0、既存 2,715 件が集計用の列に入る
- 4 区分(ハウス・委員会・クラブ・マイプロ)のテスト申請が、それぞれ申請額ちょうど集計に乗る
- 期の途中で予算タブに行を足して `sync` → フォームと manifest に選択肢が出て、その申請も集計に乗る(自動実行のトリガーもコピーで確認済み。予算タブ以外の編集では走らない)
- 口座未登録の分岐: 口座 4 項目が入る。登録済みでは入らない
- 承認・払い戻しの行ずれ: 移行後とテスト送信後で 0
- レシート添付(ファイルアップロード)付きの送信

見つかって直したこと:

- `プロセスチェックシート` のフィルタで隠れた行には、スクリプトの数式書き込みがエラーなしで無視される → 書く間だけフィルタ条件を外す(`unfiltered`)
- 共有ドライブ上のフォームは、ファイルアップロード質問があると回答を受け付けない。シートのコピーはマイドライブに作れるが、シートに付いたフォームのコピーは元と同じ共有ドライブにできる → 検証用のフォームのコピーからはアップロード質問を外す。本番はその場で移行するので影響なし
- シートのコピーに付いたフォームには `FormResponse.submit()` が使えない → テスト申請は prefill URL をブラウザで送信

移行で触らない既存の式(本番でも精算金額の CY 列ではなく CC 列(81)を合計し、予算名も別の列で照合している。意図どおりか要確認):
委員会タブ F9、クラブタブ D15・E15・F15。

## 手順

1. **バックアップ**: 本番シートを「ファイル → コピーを作成」。本番フォームも Drive でコピーを作る(フォームには版履歴が無い)。コピーは共有ドライブではなくマイドライブに置く。
2. 回答が少ない時間帯を選び、関係者に数分止まることを伝える。
3. `cd gas && clasp push`。スクリプト プロパティに `REHEARSAL_SHEET_ID` が**無い**こと(あると対象がリハーサル用コピーになる)。
4. Apps Script エディタ → プロジェクトの設定 → スクリプト プロパティに `ALLOW_PROD` = `yes` を足す。
5. エディタで `migrateProduction` を実行する(初回はトリガー作成の権限を求められる)。回答受付を止めて移行し、予算タブの変更で `sync` が走るトリガーを設定し、終わったら受付を戻して `ALLOW_PROD` を消す(失敗しても消す)。
6. ログを確認する:
   - `changedValues: 0`(予算タブの値が変わっていない)
   - `alignMoved: 0`(承認・払い戻しの行がずれていない)
   - `skipped` は上の 4 セルだけ
   いずれかが違えば、手順「戻し方」で戻す。
7. 本番フォームを prefill URL で開き、各区分の選択肢と移動先を確認する(送信はしない)。
8. manifest を本番向けに出す: `clasp deploy -i <manifest のデプロイ ID>` で新しい版にし、エディタで `info` を実行して URL を取る。
   URL にはトークンが入るので、**リポジトリにはコミットしない**。配布する Skill の `SKILL.md` の `<MANIFEST_URL>` にだけ入れる。
9. 自動同期を確認する: エディタの「トリガー」に `onBudgetChange`(スプレッドシートから・変更時)が 1 つあること。予算タブのどこかの予算項目を 1 文字変えて数秒後にフォームの選択肢が変わり、戻すと元に戻ること。

## 期の途中の予算の追加・終了

- 追加: 予算タブの同じブロックの行をコピーして挿入し、A 列(予算名)・B 列(予算項目)を書き換える(集計式ごとコピーする)。フォームと manifest には自動で反映される。
- 終了: 行を消すか、終わった期のタブを非表示にする。過去の回答は集計用の列に残る。
- 入力途中(予算名だけ入れた状態など)も一時的にフォームに出る。行を誤って消すと選択肢もすぐ消えるので、そのときは元に戻せば選択肢も戻る。
- 自動同期が止まったら(トリガーの失敗メールが届く)、エディタで `sync` を手で実行するか `installSyncTrigger` で張り直す。

## 戻し方

- シート: 「ファイル → 変更履歴」から移行前の版に戻す(移行後に入った回答の行は、フォームから再度流れてこないので注意)。
- フォーム: 質問の削除は元に戻せない。手順 1 のコピーを見て、消したセクションと選択肢を手で戻す。フォームを差し替えると URL が変わるので、差し替えはしない。

## 検証用の関数

`step1_createTestForm`〜`step6_verify` は本番を読むだけで、書き込みはコピーにだけ行う。終わったら `cleanup`。
共有ドライブにできたフォームのコピーは、スクリプトや編集者の権限では消せない。名前の頭に `[削除依頼]` を付けて(`markForDeletion`)、共有ドライブの管理者に消してもらう。

本番と同じ手順のリハーサルは `docs/rehearsal.md`。
