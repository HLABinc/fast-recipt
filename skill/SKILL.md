# 経費申請フォームの入力

最初に Slack のキャンバス「経費申請フォームの構成(AI用)」を読んで、フォームの今の構成(質問・entry ID・選択肢・移動先)を確かめる: https://app.slack.com/docs/T01DS6D3QL9/F0CMGSYGYEN
- Slack コネクタで読めなければ、ブラウザでこのリンクを開いて読む。それもできなければ、ユーザーにキャンバスの中身をコピーして貼ってもらう。
- キャンバスは予算タブやフォームが変わると自動で更新されるので、毎回読み直す。選択肢の値はキャンバスから1文字も変えずにコピーする(全角・半角、カッコ、スペース、`｜` も同じに。違うと選択されない)。

## 手順
1. レシート画像から日付・金額・支払先・品目・消費税率・インボイス番号(T+13桁)の有無を読む。
2. 目的・予算(どのハウス/委員会/クラブ/マイプロか)など画像から分からない項目は、Slack コネクタが使えれば日付・店名・金額で検索して推定する。
3. それでも埋まらない必須項目だけを、選択肢付きで 1 回にまとめてユーザーに聞く。推定した値も一覧で見せて確認してもらう。
4. 答えるセクションの質問だけを使って prefill URL を作る。
   - 予算は「予算選択」で区分を選び、→ の先のセクションで 1 つ選ぶ(ハウスだけはハウス名と予算項目の 2 問)。
   - 口座が未登録と言われたときだけ「振込口座登録」(銀行名・支店名・口座番号・口座名義カタカナ)を答える。登録済みかどうか分からなければ聞く。
   - 公共交通機関の交通費はレシート写真不要を選ぶ(アップロードのセクションは無し)。
5. レシートはアップロードの前に PC 上のファイルにしておく(チャットに貼られた画像は `~/Downloads/receipt-YYYYMMDD.jpg` などに保存。PDF も可。1 ファイル・10MB まで)。
6. URL をブラウザで開く(組織の Google アカウントでログインしたブラウザ。添付にはログインが要る)。
   - 「Continue current draft? / 下書きを使用しますか」と出たら「Continue / 続行」を選ぶ(prefill 側を使う)。
   - 前回の下書きが prefill より優先されて、違う値が入っていることがある。1 ページ目の選択が URL と違えば、ページ下の「フォームをクリア / Clear form」を押してから URL を開き直す。
   - メールアドレス記録のチェックボックス(prefill 不可)にチェックする。
   - 「次へ」で進めながら値を確認する。ページ表示直後は選択が未反映に見えることがあるので、読み込みを待ってから確認する。
7. レシートが必要な経費は最後のページで添付する。
   - 「ファイルを追加 / Add file」→ Google のファイル選択(Picker)の「アップロード / Upload」タブ →「参照 / Browse」→ OS のファイル選択で 5. のファイルを選ぶ。
   - ブラウザ自動操作ではファイル選択ダイアログを開かずに、Picker の iframe 内の `input[type=file]` に 5. のパスを直接渡せる。
   - 添付後、ページにファイル名が出ていることを確認する。
8. 送信ボタンはユーザーの明示的な確認なしに押さない。
