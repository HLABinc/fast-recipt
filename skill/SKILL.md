# 経費申請フォームの入力

質問・entry ID・選択肢・分岐先は同じフォルダの `form.md` にある。選択肢の値は form.md から1文字も変えずにコピーする(全角・半角、カッコ、スペースも同じに。違うと選択されない)。

## 手順
1. レシート画像から日付・金額・支払先・品目・消費税率・インボイス番号(T+13桁)の有無を読む。
2. 目的・予算(どのハウス/委員会/クラブ/マイプロか)など画像から分からない項目は、Slack コネクタが使えれば日付・店名・金額で検索して推定する。
3. それでも埋まらない必須項目だけを、選択肢付きで 1 回にまとめてユーザーに聞く。推定した値も一覧で見せて確認してもらう。
4. 回答したセクションの質問だけを使って prefill URL を作る。
5. URL をブラウザで開く。
   - 「Continue current draft? / 下書きを使用しますか」と出たら「Continue / 続行」を選ぶ(prefill 側を使う)。
   - メールアドレス記録のチェックボックス(prefill 不可)にチェックする。
   - 「次へ」で進めながら値を確認し、最後のページでレシートを添付する。ページ表示直後は選択が未反映に見えることがあるので、読み込みを待ってから確認する。
6. 送信ボタンはユーザーの明示的な確認なしに押さない。

## 分岐の読み方(期初にフォームを見て人が確認したもの)
- 「→ セクション名」はその選択肢を選んだときの移動先。答えるのはたどったセクションの質問だけ。
- 予算は「予算選択」から → をたどる。→ のない予算項目に答えたら予算は終わりで、次は「費用詳細入力」。
- 例外: 「ハウス選択」の次は「ハウス予算項目選択」。
- 「振込口座登録」は口座未登録のときだけ、「レシート写真・領収書写真/PDFのアップロード」はレシート写真が必要なときだけ答える。
